# 人像影像成對比較問卷（離線產生器）

為「一拍即合」2×2×2 全因子消融實驗（構圖引導 C／畸變校正 D／個人化濾鏡 F）
產生離線的成對比較問卷，採 ITU-T P.910 比較類別評分法（CCR）。

這個資料夾目前只包含**程式碼**，不包含任何受試者照片或作答資料，可以安全地放在
public repo 裡。真正的問卷（含真人照片）由研究人員在自己電腦上執行產生器後離線
分發，**不會、也不應該**被公開部署到這個網站上。

## 這裡有什麼

- `build_survey.py`：掃描照片資料夾、產生雙盲代號、指派評分者、輸出問卷。
- `survey_template.html`：單一 HTML 問卷樣板（`file://` 離線開啟，不連網、不架站）。

## 這裡沒有、也不會有

- 受試者照片、雙盲代號照片
- `master_mapping.csv`（代號與真人照片的解盲對照表）
- 產生後內嵌真實作答資料的 `rater_XX.html`

這些都屬於受試者個資／研究資料，只留在研究人員自己的電腦上，不進版本控制、
不上傳任何伺服器。

## 怎麼跑

```bash
python build_survey.py
```

修改檔案開頭的參數：

| 參數 | 說明 |
|---|---|
| `ROOT_DIR` | 照片來源資料夾（見下方結構） |
| `OUT_DIR` | 輸出資料夾 |
| `N_RATERS` | 評分者人數 |
| `N_BASE_PER_RATER` | 每人評幾張基礎照片 |
| `MASTER_SEED` | 隨機種子，固定以利重現 |

照片來源資料夾需遞迴包含 9 張基礎照片 × 8 種配置（原圖 + C/D/F 及其組合），
檔名以 `編號_後綴.jpg` 辨識（如 `001_CDF.jpg`），詳細規則見程式內註解。

跑完後 `OUT_DIR` 會有 `rater_01.html…`、`master_mapping.csv`、
`rater_assignment.csv`、`使用說明.txt`；**這整個輸出資料夾都不要提交或部署**。

## 跟網站風格的關係

`survey_template.html` 的深色配色、字體（LXGW WenKai TC / Noto Sans TC）、
圓角卡片與膠囊按鈕，是照這個網站（`style.css`）的視覺語言做的，但**照片檢視區與
評分選取狀態刻意維持無色相**（中性灰底、白底黑字選取，不用任何強調色）——
因為色彩／膚色觀感本身就是這份問卷要測量的維度之一，介面上如果出現彩色強調色，
會污染受試者對色彩的判斷（ITU-T P.910 對觀看環境的要求）。

## 如果之後要串到網站的按鈕上

目前的架構是「每位評分者一個獨立離線檔案、人工分發」，跟「網站上一顆按鈕、
任何訪客都能點進去」是不同的部署模式。要做成後者，至少需要：

1. 改成單一進入頁 + 動態指派（用亂數種子當場算題目，而不是預先烘好 45 份檔案）。
2. 照片來源必須換成受試者同意公開使用的版本，或做成完全不涉及真人資料的
   公開示範版本。
3. 確認 `master_mapping.csv` 等解盲資料的存放位置與存取權限跟現在的離線流程
   完全隔離。

這些屬於後續整合的設計決策，留給有權限調整網站部署的人一起討論再動工。
